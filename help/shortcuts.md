# Keyboard Shortcuts & Navigation Reference

Typora Reader includes intuitive hotkeys matching standard Typora navigation.

---

## ⌨️ Primary Keyboard Shortcuts

| Shortcut (macOS) | Shortcut (Linux / Omarchy) | Action | Description |
| :--- | :--- | :--- | :--- |
| <kbd>Cmd</kbd> + <kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>O</kbd> | **Open File** | Opens the native file picker dialog to load any markdown document. |
| <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd> | **Toggle Outline** | Opens or hides the Table of Contents sidebar. Also works with <kbd>Cmd/Ctrl</kbd> + <kbd>B</kbd>. |
| <kbd>Cmd</kbd> + <kbd>F</kbd> | <kbd>Ctrl</kbd> + <kbd>F</kbd> | **Find in Document** | Opens the in-page search bar with match counter and highlights. |
| <kbd>Enter</kbd> (in search) | <kbd>Enter</kbd> (in search) | **Next Match** | Jumps to the next search occurrence in the document. |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | <kbd>Shift</kbd> + <kbd>Enter</kbd> | **Previous Match** | Jumps to the previous search occurrence. |
| <kbd>Esc</kbd> | <kbd>Esc</kbd> | **Dismiss Search** | Closes search bar and clears match highlights. |
| <kbd>Cmd</kbd> + <kbd>P</kbd> | <kbd>Ctrl</kbd> + <kbd>P</kbd> | **Print / Export PDF** | Opens the print preview, pre-styled for clean distraction-free PDF generation. |
| <kbd>Cmd</kbd> + <kbd>R</kbd> | <kbd>Ctrl</kbd> + <kbd>R</kbd> | **Reload File** | Manually re-fetches the latest document state from disk. |

---

## 🧭 Navigation & Interaction Tips

- **Table of Contents ScrollSpy**: As you scroll through your document, the left sidebar automatically updates to highlight your current section.
- **Click to Jump**: Clicking any heading in the sidebar smoothly scrolls straight to that section.
- **Outline Filter**: Type in the search box at the top of the sidebar to filter headings instantly.
- **Copy Code**: Hover your cursor over any code block to reveal the **Copy** button in the top right corner.
- **Interactive Checkboxes**: Task lists (`- [x]`) can be clicked directly in the rendered view.
- **Universal Drag & Drop**: Drag any file from Finder / Yazi / Thunar directly into the browser window to open it immediately.
