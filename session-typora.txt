1. QUICK START (macOS)
--------------------------------------------------------------------------------
The CLI is globally linked in your ~/.local/bin/typora-reader (in your PATH).

From ANY directory in your terminal:

  # 1. Auto-detect & open README.md or the local .md file in current folder:
  typora-reader

  # 2. Open a specific file in the current directory:
  typora-reader testingwebsite.md

  # 3. Open using relative paths:
  typora-reader ../other-folder/notes.md

  # 4. Open using home directory expansion:
  typora-reader ~/Documents/notes.md

  # 5. Open using full absolute path:
  typora-reader "/Users/chris/path with spaces/file.md"

Direct Browser (Zero CLI / Offline):
  - Double-click reader.html in Safari, Chrome, or Zen Browser.
  - Drag and drop any .md file directly onto the window.

2. HOW TO PORT & INSTALL ON OMARCHY ARCH LINUX (HYPRLAND)
--------------------------------------------------------------------------------
Typora Reader uses only Python 3 standard library and offline bundled assets.
Zero external dependencies, no npm build, and no pip install needed.

Step 1: Transfer the typora-Like folder to Omarchy:
  - Via Git:
      cd ".../Programming/typora-Like"
      git init && git add . && git commit -m "Typora reader"
      # push to GitHub / local remote, then clone onto Omarchy
  - Or via rsync/scp:
      rsync -avz ".../Programming/typora-Like/" user@omarchy-ip:~/Programming/typora-Like/

Step 2: Run the 1-step installer on Omarchy:
      cd ~/Programming/typora-Like
      ./install-omarchy.sh

What this sets up on Omarchy:
  ✔ ~/.local/bin/typora-reader symlinked (executable from any terminal)
  ✔ ~/.local/share/applications/typora-reader.desktop installed
  ✔ Vector icon installed to ~/.local/share/icons/hicolor/scalable/apps/
  ✔ xdg-mime registered for text/markdown (opens on file double-click in Thunar/Dolphin/Yazi)
  ✔ Hyprland App Mode: Launches with --app flag in Zen/Chrome for a clean,
    borderless native window without browser tabs or address bar.
  ✔ App launcher: Type "Typora" in SUPER + SPACE (Wofi / Walker / Rofi).
